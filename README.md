# Sojo's BLOG

个人博客网站，使用 GitHub Pages + Jekyll 搭建。

## 访问地址

🔗 https://actedkitten.github.io/blog

## 新增文章

在 `_posts/` 文件夹中创建新文件，命名格式：

```
YYYY-MM-DD-文章标题.md
```

## 文章模板

```markdown
---
layout: default
title: 文章标题
date: YYYY-MM-DD
categories: 分类
tags: [标签1, 标签2]
---

# 文章内容

你的内容...
```
